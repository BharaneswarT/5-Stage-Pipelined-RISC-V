Designed and implemented a 32-bit 5-stage pipelined RISC processor in Verilog
Developed a datapath architecture including registers, an ALU, and multiplexers to perform arithmetic operations such as addition and subtraction, with Fetch, Decode, Execute, Memory and Writeback stages.
Integrated hazard detection, data forwarding, stalling and pipeline flushing logic to ensure correct execution under data/control Hazards.
